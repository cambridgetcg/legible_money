## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Lazy confidence decay (no background jobs) | Simpler, follows fact expiration pattern |
| LevelDB over RocksDB/SQLite | Simple, proven in blockchain (Bitcoin, Ethereum) |
| Claim lifecycle: pending → verifying → accepted/rejected | Clean state machine, stake locked during verification |
| Sliding window rate limiting with tiers | Flexible, tier-based, handles burst and sustained load |
| 78/22 split for claim rewards (vesting/research) | Matches existing fee routing ratio |
