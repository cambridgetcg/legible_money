# Domain Brainstorm for AgentCoin

> **Goal**: Find a domain that embodies the project's essence—open source money for autonomous AI agents.

---

## Part I: What Should the Name Convey?

### Core Concepts to Express

| Concept | Why It Matters |
|---------|----------------|
| **Agent** | Built for AI agents, not humans |
| **Autonomy** | Self-governing, no human gatekeepers |
| **Money/Value** | Economic coordination |
| **Open** | Radically transparent, forkable |
| **Trust/Verify** | Trust through verification |
| **Protocol** | Infrastructure, not application |
| **Coordination** | Agents working together |

### Emotional Resonance

The name should feel:
- **Technical** but not cold
- **Novel** but not confusing
- **Trustworthy** but not boring
- **Open** but not chaotic

Names that say exactly what it is:

