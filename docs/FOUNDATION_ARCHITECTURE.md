│  ┌────────────────────────────────────────────────────────────────┐     │
│  │  Primary: SHA-512 (truncated as needed)                         │     │
│  │  Content addressing: SHA-512/256                                │     │
│  │  Fast hashing: BLAKE3 (for non-critical paths)                  │     │
│  │                                                                  │     │
│  │  Usage:                                                          │     │
│  │    • Block hashes                                               │     │

│  │    },                                                            │     │
│  │                                                                  │     │
│  │    // Body                                                       │     │
│  │    transactions: Transaction[],                                 │     │

│  │    proposer_signature: bytes,                                   │     │

│  └────────────────────────────────────────────────────────────────┘     │
│                                                                          │
│  CONSENSUS ROUNDS                                                        │
│  ┌────────────────────────────────────────────────────────────────┐     │
│  │                                                                  │     │
│  │  ROUND PHASES:                                                   │     │
│  │                                                                  │     │
│  │  1. PROPOSE (500ms)                                             │     │
│  │     ├── Leader selected via VRF                                 │     │
│  │     ├── Leader builds block                                     │     │
│  │     └── Leader broadcasts proposal                              │     │
│  │                                                                  │     │
│  │  2. PREVOTE (500ms)                                             │     │
│  │     ├── Validators verify proposal                              │     │
│  │     ├── Validators broadcast prevote                            │     │
│  │     └── Collect 2/3+ prevotes                                   │     │
│  │                                                                  │     │
│  │  3. PRECOMMIT (500ms)                                           │     │
│  │     ├── If 2/3+ prevotes: broadcast precommit                   │     │
│  │     ├── Collect 2/3+ precommits                                 │     │
│  │     └── Lock block                                              │     │
│  │                                                                  │     │
│  │  4. COMMIT (500ms)                                              │     │
│  │     ├── If 2/3+ precommits: commit block                        │     │
│  │     ├── Update state                                            │     │
│  │     └── Start next round                                        │     │
│  │                                                                  │     │
│  │  TIMING:                                                         │     │
│  │    Target block time: 2 seconds                                 │     │
│  │    Finality: 1 block (instant with 2/3+ commits)               │     │
│  │                                                                  │     │
│  └────────────────────────────────────────────────────────────────┘     │
│                                                                          │
│  VALIDATOR SET                                                           │
│  ┌────────────────────────────────────────────────────────────────┐     │
│  │  Selection:                                                      │     │
│  │    • Top N validators by stake (N = 100 initially)              │     │
│  │    • Minimum stake: 10,000 LGM                                  │     │
│  │    • Epoch: 10,000 blocks (~6 hours)                            │     │
│  │                                                                  │     │
│  │  Rotation:                                                       │     │
│  │    • Set recalculated each epoch                                │     │
│  │    • Gradual rotation (max 10% change per epoch)                │     │
│  │    • Jailed validators excluded                                 │     │
│  │                                                                  │     │
│  │  Rewards:                                                        │     │
│  │    • Block reward: Protocol emission                            │     │
│  │    • Transaction fees: Distributed to validators                │     │
│  │    • Verification fees: To participating validators             │     │

│    │                         │                        │                  │

  Account lookups:      < 1ms
  Fact lookups:         < 5ms

  Transaction latency:  < 200ms to mempool

STORAGE:
  State size (year 1):  ~100 GB
  Growth rate:          ~10 GB/month
