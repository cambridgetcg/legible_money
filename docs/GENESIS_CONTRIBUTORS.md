## Why Early Participation Has Natural Advantages

Without any special allocation, early participants still benefit:

### 1. Higher Emission Rate
```
YEAR 1: 1,000,000 LGM/day emission
YEAR 2: 500,000 LGM/day
YEAR 3: 250,000 LGM/day
...

Early participants work when MORE tokens are being distributed.
No special treatment—just timing.
```

### 2. Less Competition
```
EARLY: Few contributors → More bounties per person
LATER: Many contributors → More competition

Same bounty pool, fewer people = larger share.
No privilege—just economics.
```

### 3. Foundational Work
```
EARLY: Build the foundation → Referenced forever
LATER: Build on the foundation → Less visibility

Early work has lasting impact.
No allocation—just contribution history.
```
